# ДПО НИУ ВШЭ — аналитика + ИИ-прогноз

Анализ программ дополнительного профессионального образования (ДПО) НИУ ВШЭ:
дашборды по историческим данным + прогноз на следующий год через OpenAI GPT.

## Установка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Положи исходный файл выгрузки рядом со скриптами под именем `programs.xls`
(лист `TDSheet`, данные с 4-й строки).

## Запуск

```bash
export OPENAI_API_KEY=sk-...
.venv/bin/python3 main.py
```

При первом запуске автоматически создаётся `programs.parquet` из `programs.xls`.

### Аргументы

| Аргумент | По умолчанию | Что делает |
|---|---|---|
| `--direction "название"` | — | Фокус прогноза на конкретном направлении подготовки |
| `--model gpt-4o-mini` | `gpt-4o-mini` | Модель OpenAI |
| `--output-dir output` | `output` | Папка для дашбордов и прогноза |
| `--skip-ai` | выкл. | Пропустить вызов GPT (без ключа), только дашборды |

Пример:

```bash
.venv/bin/python3 main.py --direction "Анализ данных(Data Science) и аналитика"
```

## Что получаешь на выходе

В указанной `--output-dir` (по умолчанию `output/`):

- `heatmap.png` — тепловая карта числа программ по направлениям и кампусам
- `top_directions.png` — топ-5 направлений по числу программ
- `forecast.txt` — текстовый прогноз ИИ: какие программы, в каком количестве
  и на каком кампусе стоит запускать в следующем году (если не указан `--skip-ai`)

В консоль также печатаются сводная статистика и топ-5 направлений.

## Как это устроено

```
programs.xls → data_ingestion.py → programs.parquet
                                         │
                    ┌────────────────────┼────────────────────┐
                    ▼                    ▼                     ▼
            gap_engine.py          dashboard.py           ai_forecast.py
        (индекс предложения S)   (heatmap, топ-5 PNG)   (тренд по годам → GPT)
                    │                    │                     │
                    └────────────────────┴─────────────────────┘
                                         ▼
                                     main.py (CLI)
```

- **`data_ingestion.py`** — читает `.xls`, приводит колонки к рабочим именам,
  чинит русскую локаль (запятая как десятичный разделитель).
- **`gap_engine.py`** — считает индекс предложения S(направление, кампус, год).
  `compute_gap` сравнивает S с спросом D, если он есть (реальных данных по
  спросу нет, есть только демо в `gap_demo.py`).
- **`dashboard.py`** — сводная статистика, топ-5 направлений, тепловая карта
  (PNG через matplotlib — Kaleido/Chrome для plotly здесь недоступны).
- **`ai_forecast.py`** — агрегирует тренд числа программ по годам (2019–2026)
  для топ-25 пар направление+кампус и просит GPT спрогнозировать следующий год
  **на основе тренда предложения**, а не подтверждённого спроса (реальных
  данных о спросе в проекте нет).
- **`main.py`** — точка входа, связывающая всё в один CLI-запуск.

Вспомогательные файлы для разовых проверок: `top_dto.py`, `gap_demo.py`, `open.py`.

## Требования

- `OPENAI_API_KEY` в переменных окружения — без него `main.py` всё равно
  сохранит дашборды, но пропустит прогноз с понятным сообщением.
- Из сети домен `api.openai.com` может быть заблокирован
  прокси/файрволом.
